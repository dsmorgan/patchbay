patchbay

One console for a small network or homelab: physical topology, live health, an IPAM overlay, config history, patch panels, and self-contained HTML snapshots you can open with the network down.

Open the live demo →

The demo is a break-glass snapshot of a fictional network — every name, address, and MAC is invented. It works entirely offline; a real deployment's nightly snapshot looks exactly like this, built from your own network. Generate your own with patchbay demo — see the README.
